2What the counters mean

mode=point · requested=1 · SVG marks=1

Build time measures this page's JavaScript element-generation and DOM insertion pass. It is a local observation—not a GPU benchmark, a cross-device comparison, or evidence of the .NET backend's performance.

This playground deliberately uses SVG so its shapes and connections are inspectable. The 10,000-point step is a stress experiment; SVG element count and DOM overhead are part of what we're learning. Visualize's current C# contracts are not executed by this page. Visualize repository · SimpleDemos
